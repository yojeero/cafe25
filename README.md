#### Cafe25 is a radio app.

Cafe25 is a minimal, premium online radio player focused on chillout, lounge, pop, and disco sounds and streams music 24/7 via a lightweight, vanilla player.

#### Tech Stack   
```
Bun | Vite | Tailwind CSS | Vanilla JS   
```
